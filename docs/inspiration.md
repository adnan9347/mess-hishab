# Design references

The original plan was to pull references with the Mobbin connector. Its search needs a paid Mobbin plan, so these
references come from well-known, widely studied patterns instead. When you have Mobbin access, search these apps to
compare against the screens here.

| Pattern borrowed | Reference apps | Used in |
|---|---|---|
| Group balances with "owes / gets back" on each person, one consistent colour pair | Splitwise, Tricount | Mess → members list |
| Settle-up as a short list of transfers, not a matrix | Splitwise "Settle up", Tricount "Reimbursements" | Settlement card, close-month dialog |
| Huge amount display with a full-width numeric keypad and quick amounts | Cash App, bKash / Nagad send money, Revolut | Pay deposit, Add bazar |
| Large daily check-in toggles that fill with colour when done | Streaks, Habitify, Apple Reminders | Today meal toggles |
| Progress ring summarising "how complete" with the number inside | Apple Fitness rings, Oura readiness | My Hishab dues ring |
| Line chart with a soft gradient fill and index tooltip for recent history | Revolut analytics, Robinhood | Last 30 days chart |
| Welcome screen with product preview art and two stacked CTAs at the bottom | Monzo, Wise onboarding | Welcome |
| Six-box code entry with auto-advance and paste | WhatsApp / bank OTP screens | Join with invite code |
| Bottom tab bar + context FAB on mobile, sidebar on desktop | Google Pay, Linear, Notion | App shell |
| Shareable end-of-period card | Spotify Wrapped (toned down), bank monthly statements | Month settlement export |

Patterns only — no branding, colours or illustrations were copied.
